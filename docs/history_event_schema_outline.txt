notes:
- the 'reason' pointer refers to spell/ability causing the event, or the event causing the trigger
  (e.g. trigger [] 'etb: deal 1 to each opponent', self, 'impact tremors', cause='move_zone[...]{...}')
- since abilities are already objects that go on the stack they can be stored in the void/phantom zone once they leave so they can still be pointed to
- passing priority and turn/phase changes are implicit
- multiple targets should be ordered set to handle cases where different targets are subject to different effects
- blockers must be ordered
